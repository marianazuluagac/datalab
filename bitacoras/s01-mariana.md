# Semana 1 - Actividad 1

## a) Cosas de las que se necesita guardar información

En DataLab se necesita guardar información sobre:

- Científicos de datos.
- Proyectos.
- Datasets.
- Experimentos.
- Modelos entrenados.
- Métricas de desempeño.

## b) Preguntas para el equipo de ciencia de datos

- ¿Un científico de datos puede participar en varios proyectos?
- ¿Un proyecto puede tener varios científicos de datos?
- ¿Un experimento puede producir más de un modelo?
- ¿Un dataset puede utilizarse en varios experimentos?
- ¿Un modelo puede evaluarse con varias métricas?
- ¿Una métrica puede utilizarse para evaluar diferentes modelos?
- ¿Puede existir un experimento que no produzca ningún modelo?

## c) ¿Qué es un experimento en DataLab?

Un experimento es una ejecución realizada por un científico de datos dentro de un proyecto. Utiliza un dataset, tiene una fecha de ejecución y una configuración con los hiperparámetros utilizados. Si el resultado es exitoso, puede producir un modelo entrenado.
